# JVR Water Tank Cleaning Services

Professional, hygienic, and affordable overhead and underground water tank cleaning services for homes, apartments, and commercial properties in Chikkadpally, New Nallakunta, Hyderabad.

## Features
- **Modern Next.js 15 & React 19** architecture
- **Static HTML Export (`output: 'export'`)** for instant performance and Netlify hosting
- **Tailwind CSS** responsive design across all mobile and desktop viewports
- **SEO & Schema Markup (JSON-LD)** for LocalBusiness, Service, Article, and FAQ
- **24/7 Direct Contact & WhatsApp Lead Funnel**

## Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
The static export will be generated in the `out/` directory and deployed via `netlify.toml`.
